# Kiroween 2026 — Mix & Match Templates

This repo contains ready-to-adapt templates, steering docs, specs, and mix-and-match ideas for all four Kiroween 2026 categories.

## How to use
1. Copy the relevant category files into your project repo.
2. Keep `.kiro/` at the root of each project.
3. Mix elements from `shared/` or other categories as needed.
4. Use Kiro (specs + steering + hooks) to flesh out the rest.

## Project repos created
- [kiroween-sloot-reborn](https://github.com/kapasainitishreddy/kiroween-sloot-reborn) — Resurrection
- [kiroween-lamarr-link](https://github.com/kapasainitishreddy/kiroween-lamarr-link) — Frankenstein
- [kiroween-necro-template](https://github.com/kapasainitishreddy/kiroween-necro-template) — Skeleton Crew
- [kiroween-haunted-terminal](https://github.com/kapasainitishreddy/kiroween-haunted-terminal) — Costume Contest

## Mix-and-match ideas
- Take the compression pipeline from Resurrection and wrap it in the Costume Contest UI.
- Use the hop protocol from Frankenstein as one of the two apps in Skeleton Crew.
- Shared UI primitives from Skeleton Crew can be dropped into any other project.
